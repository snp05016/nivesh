## Description
Spec 3.5 routes and batch rules. All Portfolio/Transaction reads opt in with include_mf. (1) money_cas_import.py: NOTICE_VERSION='cas-v1', MAX_PDF_BYTES=10_000_000, MAX_BODY_BYTES=15_000_000, PREVIEW_TTL=24h, DAILY_ATTEMPTS=10; CasImportError(code, status, retry_after=None). preview(user_id, pdf_base64, password, consent_notice_version, attest_own_statement), in order: consent -> 422 CONSENT_REQUIRED; len(password) > 64 -> 422 WRONG_PASSWORD; one DELETE purging parsing/previewed/failed/cancelled rows older than 24 h (all users); quota: user rows created in the last 24 h >= 10 -> 429 QUOTA_EXCEEDED, retry_after = seconds until the oldest drops out; base64.b64decode(validate=True) error -> 415 NOT_A_PDF; > MAX_PDF_BYTES -> 413 FILE_TOO_LARGE; not b'%PDF' -> 415; sha256; committed batch with the same (user, sha) -> 409 ALREADY_IMPORTED; set other previewed rows of the same (user, sha) to 'cancelled' with preview_json NULL; insert status 'parsing' with consent fields; commit; parse_cas_pdf; CASParseError -> status 'failed' + error_code, commit, raise (WRONG_PASSWORD/UNSUPPORTED_STATEMENT/DEMAT_CAS_NOT_SUPPORTED 422, PARSE_TIMEOUT 504, PARSE_BUSY 503 retry_after 30); existing_cas = latest CAS ADJUST date per MF ticker with import_batch_id not null; manual = ISIN tickers with rows whose import_batch_id is null; plan; store preview_json (plans + statement dates + cas_type + schemes_total), status 'previewed'; return the preview contract. commit(user_id, batch_id): not the user's -> 404; committed -> 409 ALREADY_COMMITTED; cancelled or older than 24 h -> 410 PREVIEW_EXPIRED; one get_session(): for each 'balance' plan ledger_service.restate_position(session, user_id, isin, qty, price, date=UTC midnight of statement to, notes='CAS balance', asset_class='MF', import_batch_id=batch.id, client_request_id=key, company_name=name) (None -> skipped duplicate); status 'committed', committed_at, counts, preview_json None; compliance_service._log_action(session, user_id, 'cas_import_committed', {'batch_id','schemes','rows'}); flush; IntegrityError -> rollback, 409 ALREADY_IMPORTED; LedgerError -> rollback, 409 LEDGER_CONFLICT; one commit. cancel: previewed -> 'cancelled', preview_json None (204); else 404. undo: committed only (else 404); remove_import_batch (LedgerError -> 409 UNDO_WOULD_OVERSELL, rollback); delete the batch; _log_action 'cas_import_undone'. list_imports: previewed and committed, newest first. (2) routers/money_imports.py: APIRouter(prefix='/api/v1/me/imports', tags=['Money']); every route require_auth + require_flag('money_cas_import'). POST /cas/preview is async def with request: Request: Content-Length > MAX_BODY_BYTES -> 413; read request.stream() counting bytes, abort at the cap -> 413 FILE_TOO_LARGE; json.loads; CASPreviewBody(pdf_base64: str, password: str, consent_notice_version: str, attest_own_statement: bool).model_validate in try, ValidationError/JSON error -> 422 {'code':'INVALID_REQUEST','message':'The upload could not be read.'} with no input echo; then await run_in_threadpool(preview, ...). Other routes plain def: POST /{batch_id}/commit, POST /{batch_id}/cancel (204), DELETE /{batch_id}, GET ''. Errors HTTPException(status, detail={'code','message'}), Retry-After on 429/503. routers/money.py needs no edit (registry).
