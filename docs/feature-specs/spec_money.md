### 2.3 Ledger model
- portfolio_transactions is the only source of truth; DB-09's (user, ticker) replay and read model stay. No per-group state.
- Auto SPLIT rows (notes start 'auto: corporate action') apply at most once per (date, ratio) in the replay, so MATH-07's one-row-per-group never double-applies.
- `asset_class` 'EQ'|'MF' on ledger and read model; MF tickers are ISINs.
- `ledger_service.is_opening_balance(tx)`: BUY whose notes start (case-insensitive) with 'opening balance' or 'legacy migration backfill'.
- `ledger_service.adjust_kinds(rows)`: each ADJUST is 'close' (q <= 1e-9), 'noop' (same shares within 1e-6 and per-unit cost within 0.006 of the running replay) or 'restate'.
- CAS rows: ADJUST with import_batch_id, key in client_request_id ('casbal:'+sha256(isin|statement_to|units 3dp)[:48]).
- multi_asset_transactions is not merged; its POST returns 410.
- Float storage (FIX DB-25), Decimal maths in services.
- One migration, ea2f610ceb51 (4).

### 2.4 Mutual-fund isolation (one guard)
database.py registers a `do_orm_execute` listener on Session: ORM SELECTs (not column refreshes or relationship loads) get `with_loader_criteria(Portfolio, Portfolio.asset_class == 'EQ', include_aliases=True)` unless the statement has `execution_options(include_mf=True)`. Verified with SQLAlchemy 2.0.50: entity, column, multi-column, select(), get() and lazy loads are filtered; opt-in works; refresh of an opted-in row works; Core `table.select()`, `text()` and bulk DELETE are not filtered, so DB-06 erasure and the platform export still see every row. Effects:
- All ~15 existing readers (copilot, analysis/daily-action LLM contexts, red flags, PDF export, research_repo.extra_symbols, harvesters, charts, admin) see stocks only, so ISINs never reach yfinance, the engine or an LLM.
- Only these may opt in (enforced by a test): services/ledger_service.py, services/money_*.py, scripts/reconcile_ledger.py, routers/portfolio.py (portfolio_endpoint, header-gated), services/portfolio_snapshot.py. services/money_*.py must not import any LLM client.
- The raw-SQL reader services/ticker_matcher.py gets `AND COALESCE(asset_class,'EQ') = 'EQ'`.
- v1 limitation (documented): Home summary, net worth, morning brief and other non-money screens show stocks only.

### 3.3 I30 XIRR (one flow builder)
Per ticker, rows sorted (date, id):
1. Last effective ADJUST (adjust_kinds, noops ignored): with import_batch_id -> unavailable imported_without_history; 'close' -> drop rows up to it, clean restart; 'restate' -> drop earlier rows, start with -(q x close_on(ticker, IST date of the ADJUST)) dated then, approximate_start, start_reason since_edit; no close -> unavailable edited_position.
2. Opening-balance or legacy-backfill BUY -> dated parse_trade_date(Portfolio.purchase_date) (MATH-11) with approximate_start, start_reason user_entered_date; no parsable purchase_date -> unavailable start_date_unknown.
3. A holding with no ledger rows -> one synthetic BUY of shares x buy_price under rule 2.
4. BUY -(q*p+fees); SELL +(q*p-fees); DIVIDEND +(q*p); SPLIT/BONUS none.
Holding return: MATH-04 compute_benchmark(flows, terminal, nifty, as_of). Portfolio: `portfolio_cash_flows(session, user_id, quotes) -> (flows, terminal_value, excluded, approximate_start, coverage_pct, funds_excluded)`; EQ tickers only (MF not included in v1); excluded and unpriced tickers contribute neither flows nor terminal value; coverage_pct = included value / EQ value. `/portfolio/benchmark` keeps MATH-04 keys and adds excluded_tickers [{ticker, reason}], benchmark_label, approximate_start, coverage_pct, funds_excluded, unavailable_reason; return_basis 'unavailable' with insufficient_history when coverage < 50 or no_dated_holdings when nothing is included; Nifty failure -> 200 nifty_available false; 503 only when no holding is priced.

### 3.5 I28 CAS import (balance snapshot) + X-ray
Scope: CAMS/KFintech CAS (DETAILED or SUMMARY); NSDL/CDSL -> 422 DEMAT_CAS_NOT_SUPPORTED. Deferred: full history (phase 2), demat CAS, share target, re-import nudge.
Parser: casparser pinned (1.4.1 verified on PyPI Oct 2026: MIT, Python >=3.11, pypdfium2 backend; never an extra; a CI test checks casparser's dependency closure has no GPL/AGPL licence). Parsing runs in a `spawn` child per upload with RLIMIT_AS (env MONEY_CAS_PARSE_MEM_MB, default 512), killed at 30 s (PARSE_TIMEOUT); at most 2 concurrent (BoundedSemaphore; else 503 PARSE_BUSY + Retry-After 30).
