**Category:** Missing Frontend

**Goal:** Analyze the iOS frontend architecture to address this specific issue.

**Problem Statement / Description:**
Develop `MacroDashboardView.swift` to visualize data from `macro_modifiers.py` (e.g., Minskyan Risk, FII/DII Net Flows, USDINR).

It exposes powerful backend data engines to the user, closing the feature parity gap and maximizing the value of existing backend code.

**What you have to do:**
1. Read the relevant iOS Swift files (Views, ViewModels, NetworkManager).
2. Design the SwiftUI view or structural fix.
3. Implement the changes following unidirectional data flow.
4. Build and verify in Xcode / Previews.
